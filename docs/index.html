05 / WHAT THIS DOES AND DOES NOT PROVE

Small model.
Inspectable evidence.

Strict scope

2–7 nodes, at most 12 forward arcs, two integer additive minimization costs in 0–20, at most 64 suffix paths per node. Start 0, goal n−1. Parallel edges and disconnected graphs are valid. Edge IDs distinguish paths.

Independent replay

The Python checker independently enumerates forward paths, sweeps the complete objective-line arrangement and reconstructs labels and mixture vertices. The browser replay changes path traversal but shares evidence construction. Cross-engine agreement is evidence, not a formal proof.

Established theory

Weighted sums, Pareto labels and epsilon constraints are classical. This is an educational AI-planning audit, not a new solver, trained agent, routing service, safety guarantee or scale benchmark. It cannot validate supplied costs.

Units matter

Support existence is unchanged by positive rescaling, but weight breakpoints move. Expected-cost mixtures allow a different feasible set than deterministic hard-bound planning. This is not a discounted MDP or per-step randomized control policy.

Edit the bounded graph JSON

Input edits immediately clear stale evidence and disable exports. Duplicate fields, decimals, extra fields and backward arcs are rejected.
